Login Organizer

Login Organizer is a Python tool that automatically sorts text files containing credentials (email and password per site) into a clean, organized directory structure. It includes a graphical user interface (GUI) to monitor the sorting process in real time. The tool has no network access, does not verify the validity of credentials, does not decrypt anything, and does not modify source files. It requires Python 3.8 or higher and runs solely using the standard library, on Windows, Linux, and macOS.

Discord custom

I worked on a personal project involving Discord. I used the source code of Equicord—a modified Discord client—to inject my own "user plugins," written in TypeScript. The goal was to create a custom version of Discord, featuring bespoke functionality not found in the official client. Equicord is a fork of Vencord, which is itself a mod for Discord. I wrote my own plugins in TypeScript to introduce custom behaviors—such as shortcuts, interface modifications, automations, and other enhancements—that helped me save time in my day-to-day use.
